# Web Gumballs Coding Mods

A web-based platform for Gumball coding mods with Scratch-inspired styling and Google/Scratch authentication.

## Gumball's AI Generator

This project includes a polished "extra web" generator experience for creative prompt-to-web generation, plus a searchable-style AI model catalog covering video, image, music, and avatar tools.

### Included experience
- Prompt-based website generation
- Vibe selection: playful, neon, and calm
- Live HTML/CSS/JS preview output
- AI model catalog grouped by category
- Responsive layout suitable for desktop and mobile

### Run locally
Open `index.html` directly in a browser, or serve the repo with:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
